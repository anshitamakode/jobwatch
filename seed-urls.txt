# jobwatch company watchlist
#
# Run:  ./bootstrap.sh
#
# One URL per line. `add` resolves each to an ATS, VERIFIES the feed actually
# responds, and only writes it to companies.yaml if it returns postings.
# Failures are expected and free -- companies migrate ATS constantly, and
# many of these tokens are educated guesses. Re-running is safe: anything
# already in companies.yaml is skipped.
#
# To add your own: open a real job posting on any careers page, copy the URL
# from the address bar, paste it here. Any URL on the ATS host works.
#
# Twelve ATSs supported: Workday, Greenhouse, Lever, Ashby, SmartRecruiters,
# Workable, Recruitee, Eightfold, Oracle HCM, Keka, Rippling, plus a generic
# JSON-LD scraper for self-hosted pages.
#
# NOT included: Flipkart (TurboHire; robots.txt disallows automated access).
# Use a LinkedIn alert for them.
