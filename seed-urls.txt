# jobwatch company watchlist
#
# Run:  ./bootstrap.sh
#
# One URL per line. `add` resolves each to an ATS, VERIFIES the feed actually
# responds, and only then writes it to companies.yaml. Failures are expected
# and harmless -- companies migrate ATS constantly. Re-running is safe:
# anything already in companies.yaml is skipped.
#
# To add your own: open a real job posting on any careers page, copy the URL
# from the address bar, paste it here. Any URL on the ATS host works.
#
# Note on the JSON-LD section: those are self-hosted portals with no public
# API. The scraper reads schema.org JobPosting markup off a single page, so
# it only works when the page is server-rendered. Career pages that load jobs
# via JavaScript return 0 postings -- `add` tells you immediately. Drop those.
#
# Deliberately NOT included: Flipkart. They use TurboHire, whose robots.txt
# disallows automated access. Set a LinkedIn alert for them instead.
